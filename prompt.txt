### Part 2: POTD — Codeforces only (`src/components/actions/potd-actions.ts`)

In `getTodayChallenge()` (line 84-95), add an `and(eq(problems.platform, "codeforces"))` filter to the rating-based problem query:

```ts
const [problem] = await db
  .select({ id: problems.id })
  .from(problems)
  .where(
    and(
      eq(problems.platform, "codeforces"),          // ← ADD THIS
      sql`COALESCE(${problems.rating}, ${problems.externalDifficulty}) >= ${minRating}`,
      sql`COALESCE(${problems.rating}, ${problems.externalDifficulty}) <= ${minRating}`,
      notInArray(problems.id, solvedQuery),
    ),
  )
  .orderBy(sql`RANDOM()`)
  .limit(1);
```
